# Две пятёрки

Браузерная хоккейная игра-драфт в духе 7a0: каждый раунд выпадает сборная с конкретного чемпионата мира IIHF, из её состава берёшь одного игрока. За 11 раундов собираешь две пятёрки и вратаря, затем играешь чемпионат мира — группа из восьми исторических сборных и плей-офф.

- 76 составов 18 сборных, ЧМ 1977–2025 (Канада, Швеция, Россия, Чехия/Чехословакия, Финляндия, США, Словакия, Швейцария, Германия, Казахстан, Латвия, Италия, Норвегия, Беларусь, Франция, Австрия и СССР)
- у каждого игрока своя позиция — левый край, центр, правый край, левый/правый защитник; поставить не на свою позицию нельзя. Выбор игрока в драфте сразу подсвечивает его место на площадке
- матчи идут в прямом эфире по 10 секунд (есть ускорение ×2/×4): табло, периоды, голы с временем и большинством, удаления с временем штрафа, счёт других матчей тура; следующий матч запускается только по нажатию кнопки
- на площадке видно линии сыгранности между игроками — зелёная линия для игроков из одного состава, жёлтая для игроков одной страны (Чехословакия/Чехия/Словакия считаются одной страной)
- режимы: Классика, Знаток (рейтинги скрыты), Ежедневный вызов, игра по коду друга
- один файл `index.html`, без сборки и зависимостей, адаптирован под телефон

Запуск: открыть `index.html` в браузере или включить GitHub Pages для ветки `main`.

Составы — по ростерам ЧМ IIHF (Википедия, QuantHockey). Рейтинги — субъективная оценка.

## Версии

- v1.11 — вес сыгранности в формуле уравнен с весом рейтинга игроков: разброс от нулевой до стопроцентной сыгранности теперь так же решает исход, как разброс от слабейшего до сильнейшего состава по рейтингу
- v1.10 — вратарь теперь тоже участвует в сыгранности: его связь со всеми полевыми игроками (та же страна/состав) даёт бонус и рисуется линией на площадке
- v1.9 — сыгранность сильнее влияет на атаку/защиту: при полной сыгранности (100%) команда при тех же игроках побеждает заметно чаще, чем без неё; сложность против сборных-соперников сбалансирована заново
- v1.8 — ускорение прямого эфира матча ×1/×2/×4; линии сыгранности на площадке (как в FIFA) — зелёная для игроков из одного состава, жёлтая для игроков одной страны; Чехословакия теперь объединена с Чехией и Словакией для бонуса сыгранности
- v1.7 — впервые добавлены Норвегия (2017), Беларусь (2014), Франция (2017), Австрия (2013); плюс серебряный состав Швейцарии 2013 (Йоси, Нидеррайтер, Бруннер); теперь 76 составов 18 сборных
- v1.6 — добавлены сборные Чехословакии (1977, 1987), Швеции (1991, 1998), Финляндии (1994, 1999) и впервые Италии (2021); теперь 71 состав 14 сборных
- v1.5 — добавлены составы СССР 1983, 1986, 1990 и 1991 годов (теперь 7 составов СССР из 64)
- v1.4 — СССР и Россия считаются одной страной для бонуса за сыгранность земляков
- v1.3 — после установки игрока на позицию экран возвращается к составу (виден флаг и страна)
- v1.2 — фиксированные игровые позиции (левый/правый край, центр, левый/правый защитник), выбор игрока подсвечивает место на площадке, следующий матч турнира — только по кнопке
- v1.1 — матчи в прямом эфире (10 секунд), удаления, большинство, овертайм 3×3 и буллиты по правилам IIHF
- v1.0 — первая версия: драфт и мгновенная симуляция турнира (сохранена в `versions/v1.0/`)
