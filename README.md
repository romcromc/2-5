# Две пятёрки

Браузерная хоккейная игра-драфт в духе 7a0: каждый раунд выпадает сборная с конкретного чемпионата мира IIHF, из её состава берёшь одного игрока. За 11 раундов собираешь две пятёрки и вратаря, затем играешь чемпионат мира — группа из восьми исторических сборных и плей-офф.

- 64 состава 13 сборных, ЧМ 1979–2025 (включая 7 составов СССР)
- у каждого игрока своя позиция — левый край, центр, правый край, левый/правый защитник; поставить не на свою позицию нельзя. Выбор игрока в драфте сразу подсвечивает его место на площадке
- матчи идут в прямом эфире по 10 секунд: табло, периоды, голы с временем и большинством, удаления с временем штрафа, счёт других матчей тура; следующий матч запускается только по нажатию кнопки
- режимы: Классика, Знаток (рейтинги скрыты), Ежедневный вызов, игра по коду друга
- один файл `index.html`, без сборки и зависимостей, адаптирован под телефон

Запуск: открыть `index.html` в браузере или включить GitHub Pages для ветки `main`.

Составы — по ростерам ЧМ IIHF (Википедия, QuantHockey). Рейтинги — субъективная оценка.
